Fonts bundled here are used by the image tools (watermark, meme captions, photo editor text) via PHP GD's `imagettftext`. Both are free, open-source, and licensed under the SIL Open Font License 1.1, which permits redistribution and commercial use.

- `Anton-Regular.ttf` — [Anton](https://fonts.google.com/specimen/Anton) by Vernon Adams, from the [google/fonts](https://github.com/google/fonts) repository (`ofl/anton`).
- `Inter-Regular.ttf` — [Inter](https://fonts.google.com/specimen/Inter) by Rasmus Andersson, from the [google/fonts](https://github.com/google/fonts) repository (`ofl/inter`), variable font.
